# 微信通知退役记录

2026-10-27，本人明确要求移除交接待办转发到微信的功能，并从服务器撤除。此取消覆盖此前启用及全访客自动放行的授权。

服务端已移除微信通知出站队列、Unix socket 传输及其配置接入；创建、恢复、状态与追加问题的返回值不再提供微信 `notification` 描述。客户端保留请求 ID、来源、用户名、原 handle、页面链接与答复游标，继续处理问卷、反馈和求助。

旧请求中的 `notificationEvent`、`notificationOutbox`、`requestUrl` 仅随原记录保留，不主动读取、迁移、删除或回放。历史通知、真实问题与答复均不因退役清空，不能用旧通知做重试或验证。

交接 App 自身的 Web Push、发送回执、手机订阅、VAPID 身份、PWA、自定义 HTML／JSON 反馈桥接及原有来源隔离继续使用。移除此功能不删除微信机器人或交接 App，不授予任何真实答复的消费权限。

服务器专用桥接环境文件、systemd drop-in、socket 与组权限由协调侧备份后撤除，相关私有运维记录由其统一更新。普通代码仍沿原 GitHub main push 事件链发布；旧版本文档和配置备份只作历史记录，不能据此重新启用微信通知。
